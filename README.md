# 🧠 Second Brain — العقل الثاني والخزنة الذكية

نظام شخصي يعمل على جهازك فقط، ويجمع في مكان واحد:

- **خزنة مشفرة** (AES-256-GCM) للإيميلات وكلمات المرور وأكواد الاسترداد ومفاتيح API والملفات الحساسة، تُفتح بكلمة مرورك أو بـ **مفتاح طوارئ عائلي** مطبوع.
- **رادار المشاريع**: يفحص مشاريعك، ويوثّقها في Obsidian، ويؤمّن ملفاتها الحساسة (`.env`، keystore...)، وينبّهك إن رُفع ملف حساس على Git.
- **ذاكرة مشتركة** لأدوات الذكاء (Claude Code و Google Antigravity) عبر خادم MCP، مع أرشفة محادثاتك بعد حذف الأسرار منها.
- **مساعد ذكي** بالعربية بوضعين، للقائد وللعائلة، بلا فواتير إضافية. يجرّب بالترتيب:
  - Claude عبر اشتراك Pro (Claude Code).
  - Ollama.
  - معرفة محلية بلا إنترنت.
- **محادثات محفوظة** مشفّرة بمفتاح الخزنة، و**صوت عربي** يُولَّد على جهازك (XTTS-v2 أو Kareem).
- **يعمل في الخلفية** عند تشغيل الحاسوب، ويُفتح في نافذة مستقلة بأيقونته.
- **وضع العائلة والطوارئ**: واجهة مبسطة، وكتيب طوارئ للطباعة، ونسخ احتياطية مشفرة تُستعاد حتى على جهاز جديد.

> مكتوب بـ **Node.js + TypeScript بلا أي حزمة خارجية**، حتى يبقى قابلاً للتشغيل بعد سنوات ومن فلاشة USB.

## ⚡ التشغيل السريع

**المتطلبات:** Windows أو macOS، و [Node.js](https://nodejs.org) الإصدار **24** أو أحدث (يشغّل ملفات TypeScript مباشرة).

1. **التثبيت (مرة واحدة لكل جهاز):** يشغّل البرنامج في الخلفية عند تسجيل الدخول، وينشئ اختصار «Second Brain» بأيقونته. لا يحتاج صلاحيات مسؤول، وتلغيه أداة `uninstall-windows.ps1`.
   ```powershell
   powershell -ExecutionPolicy Bypass -File Second-Brain-System\install\windows\install-windows.ps1
   ```
   على الماك: `bash Second-Brain-System/install/macos/install-macos.sh`
2. افتح **Second Brain** من سطح المكتب أو قائمة ابدأ؛ يُفتح في نافذة مستقلة. بديل بلا تثبيت: `Launch-Second-Brain.bat`. الخادم متاح لهذا الجهاز فقط.
3. من قسم **الخزنة** أنشئ كلمة مرور رئيسية (10 أحرف على الأقل).
4. سيظهر **مفتاح الطوارئ مرة واحدة فقط** — اطبع كتيب الطوارئ فوراً من قسم **الطوارئ** واحفظه في مكان آمن.

أوامر بديلة من داخل `Second-Brain-System/`:

```bash
node src/features/dashboard-app/desktop-server.ts
```

```bash
node tests/run-all-tests.ts
```

```bash
node src/tools/code-registry-scanner.ts
```

## 🤖 ربط الذكاء الاصطناعي

| المزوّد | كيف يُفعَّل |
| :--- | :--- |
| Claude | احفظ المفتاح من **الخزنة ← مفاتيح الذكاء الاصطناعي** (أو متغير البيئة `ANTHROPIC_API_KEY`). النموذج الافتراضي `claude-opus-5-5`. |
| Gemini | احفظ المفتاح بالطريقة نفسها (أو `GEMINI_API_KEY`). النموذج الافتراضي `gemini-3.8-flash`. |
| Ollama | شغّل Ollama على جهازك ونزّل النموذج (`llama3.2` افتراضياً). يعمل بلا إنترنت. |
| المعرفة المحلية | تعمل دائماً كآخر خيار، بلا إنترنت ولا مفاتيح. |

الترتيب والنماذج قابلة للتعديل من صفحة **الإعدادات**. مفاتيح الخزنة لا تُستخدم إلا والخزنة مفتوحة، ومحتوى الخزنة لا يُرسل لأي مزوّد أبداً.

### خادم الذاكرة المشتركة (MCP)

أضف هذا المدخل إلى إعدادات أداة الذكاء (`mcpServers`)، مع تعديل المسار حسب مكان المجلد على جهازك:

```json
{
  "second-brain": {
    "command": "node",
    "args": ["<مسار المجلد>/Second-Brain-System/src/tools/mcp-memory-server.ts"]
  }
}
```

- **Claude Code:** في `~/.claude.json` (لكل المشاريع) أو في ملف `.mcp.json` داخل مشروع محدد.
- **Google Antigravity:** في `~/.gemini/antigravity/mcp_config.json`.

الأدوات المتاحة: ملف القائد، نظرة المشاريع، تفاصيل مشروع، استرجاع الذاكرة، البحث فيها، وتسجيل القرارات. الخادم لا يصل إلى الخزنة إطلاقاً.

## 🔐 نموذج الأمان باختصار

- الخادم يستمع على `127.0.0.1` فقط، ويرفض أي طلب من موقع آخر (فحص Host و Origin، JSON فقط، حد 1MB).
- الخزنة: مفتاح بيانات عشوائي مغلَّف بكلمة المرور وبمفتاح الطوارئ (scrypt `N=2^17`)، حفظ ذرّي مع 5 نسخ سابقة، ولا تُمسح أبداً.
- جلسة الخزنة في الذاكرة فقط بكوكي `HttpOnly; SameSite=Strict`، تُقفل بعد 10 دقائق خمول، مع تأخير متصاعد بعد المحاولات الخاطئة.
- وضع العائلة يعرض الحسابات فقط؛ التعديل وتغيير كلمة المرور للقائد.
- الواجهة بسياسة CSP صارمة، وكل نص يُعرض عبر `textContent`.
- الأسرار تُحذف تلقائياً من المحادثات المؤرشفة وسجلات الذاكرة وسياق المساعد.

## 💾 النسخ الاحتياطي والاستعادة

- من قسم **الطوارئ**: «نسخة احتياطية الآن» (يُحتفظ بآخر 10 نسخ، ويمكن تحديد مجلد إضافي مثل فلاشة من الإعدادات).
- النسخة تُفتح **بكلمة المرور أو بمفتاح الطوارئ** حتى على جهاز جديد.
- الاستعادة من **وضع العائلة ← استعادة نسخة احتياطية**: معاينة أولاً، ثم استعادة إلى مجلد جديد فارغ فقط.

## 🛠️ حل المشاكل

| المشكلة | الحل |
| :--- | :--- |
| `Node.js is not installed` | ثبّت Node.js 24 أو أحدث ثم أعد التشغيل. |
| المنفذ 4777 مشغول | غيّر `serverPort` في `config/settings.json`. |
| «كلمة المرور أو مفتاح الطوارئ غير صحيح» | تأكد من المفتاح المطبوع؛ الحروف الصغيرة والمسافات مقبولة، وخانة التحقق الأخيرة تكشف أخطاء الكتابة. |
| «محاولات كثيرة خاطئة» | انتظر المدة المعروضة (تتضاعف مع كل محاولة خاطئة). |
| المساعد يجيب بالمعرفة المحلية فقط | افتح الخزنة (لاستخدام المفاتيح المحفوظة فيها) أو أضف مفتاحاً، وراجع سطر حالة المزوّدين أسفل المحادثة. |
| خادم MCP لا يظهر في الأداة | أعد تشغيل الأداة بعد إضافة المدخل، وتأكد من صحة المسار وأن `node` مثبّت. |
