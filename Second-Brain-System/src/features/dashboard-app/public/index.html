المزامنة بين الأجهزة

كل جهاز يعمل وحده بالكامل، وتكتب وتعدّل من أي جهاز متى شئت. التغييرات تنتقل بين الأجهزة مشفّرة بمفتاح الخزنة عبر مجلد Google Drive، فلا يرى Google أي محتوى. إن عدّلتَ الشيء نفسه على جهازين قبل المزامنة تُحفظ النسختان ويظهر لك تعارض لتختار، فلا يضيع شيء.

هذا الجهاز

المزامنة تلقائية كل دقيقتين، وعند فتح الخزنة وقفلها. قبل كل دمج تُحفظ نسخة احتياطية من حالة هذا الجهاز، وإن فشل الدمج تعود الحالة السابقة تلقائياً.

💻 الأجهزة

    🛑 حذف جماعي ينتظر تأكيدك

    اختفى عدد كبير من العناصر دفعة واحدة (أو مجلد كامل). لم يُحذف شيء من الأجهزة الأخرى بعد: إن كنت حذفتها أنت فأكّد، وإلا أعدها.

    ⚠️ تعارضات تنتظر قرارك

    عُدّل الشيء نفسه على جهازين قبل أن يرى أحدهما تعديل الآخر. النسختان محفوظتان: اختر أيهما تبقى، والأخرى تذهب إلى السلة 30 يوماً. الأسرار لا تُحسم تلقائياً أبداً.

    🗑️ سلة المحذوفات (30 يوماً)

    ما يُحذف على أي جهاز يبقى هنا 30 يوماً. الاسترجاع يعيده على كل الأجهزة.

      ⚙️ إعداد المزامنة على هذا الجهاز (يتطلب كلمة المرور الرئيسية)
      1. ثبّت Google Drive for desktop من google.com/drive/download وسجّل الدخول بحسابك (على كل جهاز).
      2. اختر مجلد «My Drive» أدناه (أو أي مجلد مُزامَن)، وفعّل المزامنة.
      3. افتح الخزنة بكلمة المرور الرئيسية: تبدأ المزامنة تلقائياً (وعلى الأجهزة المحدَّثة من 1.9 يتم الترحيل مرة واحدة).

      دليل ربط النماذج

      بلا فواتير إضافية: يجرّب المساعد Claude عبر اشتراكك، ثم Ollama، وإن تعذّر الجميع يجيب من المعرفة المحلية. زر «اختبار الاتصال» يرسل رسالة قصيرة ثابتة فقط (بلا أي معلومات شخصية) ويعرض النتيجة.

      🟠 Claude عبر اشتراكك (Claude Pro)

      يستخدم المساعد برنامج Claude Code المثبّت على جهازك، فيعمل باشتراك Pro نفسه بلا أي فاتورة إضافية، ويُحسب الاستخدام من حصة الاشتراك.

      1. إن لم يكن الأمر claude متاحاً في الطرفية، ثبّته مرة واحدة من PowerShell (يستخدم النسخة الموجودة داخل تطبيق Claude لسطح المكتب):& (Get-ChildItem "$env:APPDATA\Claude\claude-code" -Recurse -Filter claude.exe | Sort-Object LastWriteTime -Descending | Select-Object -First 1).FullName installعلى الماك:curl -fsSL https://claude.ai/install.sh | bash
      2. افتح نافذة طرفية جديدة وسجّل الدخول بحساب Claude Pro:claude auth login
      3. اضغط «اختبار الاتصال» أدناه.

      العزل: يعمل Claude Code هنا بلا أي أدوات ولا خوادم MCP ولا حفظ للجلسات، في مجلد مؤقت فارغ، فلا يستطيع تعديل ملفاتك أو تنفيذ أوامر. النموذج يُختار من الإعدادات (sonnet افتراضياً لتوفير الحصة، أو opus).

      🔵 Gemini عبر Antigravity

      عبر الذاكرة المشتركة

      أوقفت Google استخدام Gemini CLI لحسابات الأفراد ووجّهتها إلى Antigravity، و Antigravity لا يعمل من برنامج آخر دون واجهته. لذلك يبقى Gemini مربوطاً بـ Second Brain عبر الذاكرة المشتركة (MCP): يقرأ ملفك وسياق مشاريعك ويسجّل القرارات أثناء عملك في Antigravity، باشتراكك وبلا تكلفة إضافية.

      🦙 Ollama (محلي، مجاني، بلا إنترنت)

      على Windows (اللابتوب أو المكتبي)

      1. نزّل Ollama من ollama.com/download وثبّته (يعمل في الخلفية تلقائياً).
      2. افتح PowerShell ونزّل نموذجاً: ollama pull llama3.2
      3. تأكد أنه يعمل: ollama list
      4. في الإعدادات: العنوان http://127.0.0.1:11434 واسم النموذج نفسه.

      على MacBook Air

      1. نزّل Ollama للماك من ollama.com/download واسحبه إلى Applications ثم افتحه.
      2. من Terminal: ollama pull llama3.2
      3. نفس العنوان والإعدادات كما في Windows.

      أي نموذج يناسب جهازك؟

      • المكتبي (RTX 3090 بذاكرة 24GB): نماذج حتى نحو 32 مليار معامل بضغط 4-bit تعمل بالكامل على البطاقة، مثل عائلات Qwen أو Gemma أو DeepSeek بأحجام 27B–32B. هذا أقوى خيار محلي لديك.
      • MacBook Air M5: نماذج صغيرة ومتوسطة (3B–14B) حسب الذاكرة الموحّدة؛ مع 16GB يُفضّل 8B تقريباً، ومع 24–32GB حتى نحو 14B.
      • اللابتوب: حسب ذاكرة بطاقة الرسوميات؛ ابدأ بـ llama3.2 (3B) وجرّب الأكبر تدريجياً.

      راجع الأسماء والأحجام المتاحة في ollama.com/library. ربط Ollama المكتبي من اللابتوب والماك عبر نطاقك على Cloudflare سيُضاف في المرحلة «د» من الخطة؛ حتى ذلك الحين يقبل البرنامج Ollama على نفس الجهاز فقط.

      🔊 الصوت العربي

      يُنطق الرد بصوت عربي يُولَّد على جهازك نفسه، بلا إنترنت وبلا أي خدمة خارجية، ويعمل في أي متصفح.

      جاري فحص الصوت…

      • XTTS-v2 (الأعلى جودة): صوتا Suad Qasim و Damien Black، يعمل على كرت الشاشة. يُثبَّت على الأجهزة الأخرى بالأمر node src/tools/install-xtts-voice.ts --accept-license (نحو 4.8GB، ورخصته للاستخدام غير التجاري)، وتفاصيله في الدليل.
      • الصوت العربي المدمج Kareem (احتياطي خفيف): محرك Piper المفتوح المصدر مع الصوت العربي «Kareem». يُنزَّل مرة واحدة على كل جهاز (نحو 85MB من مصادره الرسمية: GitHub و Hugging Face) داخل مجلد vendor في المشروع.
      • أو صوت Windows العربي: إن ثبّتّ «العربية (السعودية)» من إعدادات Windows ← الوقت واللغة ← الكلام، يستخدمه البرنامج تلقائياً.
      ⚙️ متقدم: مفاتيح API (فوترة منفصلة عن الاشتراكات)

      مفاتيح API تُحاسَب برصيد منفصل عن اشتراكَي Claude Pro و Google. لا يستخدمها المساعد إلا بعد تفعيل «استخدام مفاتيح API» في الإعدادات.

      🟠 Claude API (Anthropic)

      1. افتح console.anthropic.com وسجّل الدخول.
      2. من Settings ← Billing أضف رصيداً (يُحاسب الاستخدام بعدد الكلمات).
      3. من Settings ← API Keys اضغط Create Key وانسخ المفتاح (يبدأ بـ sk-ant-).
      4. في هذا البرنامج: الخزنة ← مفاتيح الذكاء الاصطناعي، اختر Claude والصق المفتاح واحفظه.
      5. النموذج الافتراضي في الإعدادات: claude-opus-5-5 (الأقوى). للأسرع والأرخص: claude-sonnet-5-5 أو claude-haiku-5-5.
      6. اضغط «اختبار الاتصال» أدناه.

      🔵 Gemini API (Google)

      1. افتح aistudio.google.com بحساب Google.
      2. اضغط Get API key ثم Create API key وانسخ المفتاح (يبدأ بـ AIza).
      3. للاستخدام الكثيف فعّل الفوترة في مشروع Google Cloud المرتبط؛ الطبقة المجانية لها حدود يومية.
      4. في هذا البرنامج: الخزنة ← مفاتيح الذكاء الاصطناعي، اختر Gemini والصق المفتاح واحفظه.
      5. النموذج الافتراضي: gemini-3.8-flash (سريع ورخيص)، ويمكن تغييره من الإعدادات.
      6. اضغط «اختبار الاتصال» أدناه.
      🧩 ربط الذاكرة المشتركة مع Claude Code و Antigravity (MCP)

      خادم الذاكرة المشتركة مسجّل في Claude Code وفي Antigravity على هذا الجهاز، فيقرأ الوكيلان ملفك الشخصي وسياق المشروع ويسجّلان القرارات. على جهاز جديد تُسجَّل الأداة تلقائياً بالمثبّت (المرحلة «ب»)، والتفاصيل في docs/08-AI-CONNECTION-GUIDE.md.

      المشروع

      الخزنة المشفرة

      إنشاء الخزنة لأول مرة

      1. اختر كلمة مرور رئيسية قوية لا تستخدمها في أي مكان آخر.
      2. سيظهر مفتاح الطوارئ لزوجتك مرة واحدة فقط.
      3. اطبع كتيب الطوارئ فوراً واحفظه في مكان آمن.

      10 أحرف على الأقل؛ الأطول أقوى.

      الخزنة مقفلة

      👆 الدخول بالبصمة أو رمز الجهاز (Passkeys)

      بدل كتابة كلمة المرور الرئيسية كل مرة: Passkey بامتداد PRF يفتح الخزنة بتشفير حقيقي. على Windows اختر «مدير كلمات المرور في Google» (Windows Hello على Windows 10 بلا PRF)، وعلى الماك Touch ID.

      • الغلاف محفوظ على هذا الجهاز فقط: لا يُزامَن ولا يدخل النسخ. فكل جهاز يُسجَّل وحده.
      • كلمة المرور الرئيسية تبقى تعمل دائماً، وهي مطلوبة للتسجيل وللأعمال الحساسة.
      • تغيير كلمة المرور (على أي جهاز) يُلغي الـ Passkeys، فتسجّلها من جديد.

      🔐 المصادقة الثنائية (Google Authenticator)

      عند تفعيلها يُطلب رمز من 6 أرقام من تطبيق المصادقة عند فتح الخزنة بكلمة المرور فقط (لا مع البصمة ولا مع مفتاح الطوارئ). تحميك إن عرف أحد كلمة المرور على جهاز جديد. ملاحظة صادقة: هي بوابة في البرنامج لا تشفير؛ الحماية الحقيقية تبقى كلمة المرور والتشفير.

      1. افتح Google Authenticator على الهاتف ← «+» ← «مسح رمز QR»، وامسح الباركود.
      2. أو أدخل السر يدوياً (اختر «مستند إلى الوقت»):
      3. اكتب الرمز الحالي من التطبيق للتأكيد.
      🧪 قياس دعم البصمة والوجه (Passkeys)

      قبل أن تفتح البصمة أو الوجه الخزنة، نقيس ما يدعمه هذا الجهاز وهذا المتصفح. القياس يُنشئ Passkey تجريبياً باسم «Second Brain — قياس»، ثم يطلب التحقق منك مرتين. لا يُفتح شيء ولا يُحفظ أي سر، ويُحفظ التقرير على هذا الجهاز فقط.

      بعد القياس يمكنك حذف الـ Passkey التجريبي: في Windows من «الإعدادات ← الحسابات ← مفاتيح المرور»، وعلى الماك من «كلمات السر».

      🤖 مفاتيح API (متقدم — فوترة منفصلة)

      تُحفظ مشفرة داخل الخزنة، ولا يستخدمها المساعد إلا والخزنة مفتوحة. اترك الحقل فارغاً واحفظ لحذف المفتاح.

      الذاكرة المشتركة

      قرارات وملخصات العمل التي تحفظها أدوات الذكاء (Claude Code و Antigravity) عبر خادم الذاكرة، وأرشيف المحادثات في Obsidian.

      الطوارئ والنسخ الاحتياطي

      🖨️ كتيب الطوارئ للعائلة

      أدخل مفتاح الطوارئ الحالي؛ يتحقق البرنامج أنه يفتح الخزنة قبل الطباعة. الكتيب لا يُحفظ على القرص.

      💾 النسخ الاحتياطي المشفر

      تُفتح النسخة بكلمة المرور (كاملة)، أو بمفتاح الطوارئ (الجزء العائلي منها فقط)، حتى على جهاز جديد.

      🧪 تمرين الاستعادة (تحقق أن النسخة تُستعاد فعلاً)

      يستعيد أحدث نسخة في مجلد مؤقت معزول، ويتحقق من: فتح الخزنة، والمحادثات، والذاكرة، والمشاريع، وملفات Obsidian، وعدم فقدان أي ملف، ثم يحذف المجلد. الأفضل تشغيله على جهاز غير الذي أنشأ النسخة.

      👪 الخزنة العائلية

      اليوم مفتاح الطوارئ المطبوع يفتح كل الأسرار والمحادثات. بعد الترقية يفتح الخزنة العائلية وحدها: الأسرار التي تختارها هنا، وأدلة العائلة، ومحادثات العائلة.

      • يُولَّد مفتاح طوارئ جديد إجبارياً: اطبع الكتيب الجديد فوراً، وأتلف الورقة القديمة.
      • نفّذ الترقية على جهاز واحد فقط. الأجهزة الأخرى تستقبل المفاتيح بالمزامنة.
      • يمكنك لاحقاً تعليم أي سرّ بـ «👪 يظهر للعائلة» من نافذة تعديله.

      اختر ما تحتاجه العائلة (المقترح محدَّد مسبقاً):

      🗂️ نسخ قديمة يفتحها مفتاح الطوارئ القديم

      هذه النسخ كُتبت قبل الترقية، فالمفتاح القديم ما زال يفتح كل ما فيها. بعد التأكد من النسخة الجديدة احذفها، أو أبقها إن كانت الورقة القديمة قد أُتلفت.

      👪 بوابة العائلة

      ما تكتبه هنا يدخل الخزنة العائلية مباشرة، فتراه العائلة بمفتاح الطوارئ في «❤️ وضع العائلة»، ويعرفه المساعد العائلي.

      📞 جهات الاتصال المهمة

      🧭 تعليمات التعامل مع المطورين والشركات

      📝 سجل خطوات الطوارئ (0)

      كل ما يحدث في وضع العائلة يُسجَّل هنا تلقائياً (فتح الخزنة وقفلها، وأسئلة المساعد، وحذف المحادثات)، ومعه ملاحظات العائلة. السجل مشفّر بالمفتاح العائلي ولا يُعدَّل.

      🔑 تغيير كلمة المرور

      ♻️ مفتاح طوارئ جديد

      يُبطل الورقة المطبوعة الحالية فوراً. استخدمه إذا فُقدت الورقة.

      🧪 وضع التطوير

      خلال مرحلة التطوير يمكنك تصفير البرنامج للبدء من جديد. لا يُحذف شيء: الخزنة والإعدادات الشخصية والمشاريع والذاكرة والسجلات وما ولّده البرنامج في Obsidian تُنقل إلى سلة داخل data/_trash ويمكن استرجاعها. لا يمس الكود ولا الوثائق ولا ملفك الشخصي في Obsidian ولا النسخ الاحتياطية المشفرة.

      عند انتهاء التطوير اضغط «اعتماد نهائي»: يُطفأ وضع التطوير، ويختفي هذا القسم، ويرفض البرنامج التصفير بعدها.
