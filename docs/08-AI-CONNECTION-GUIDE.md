# 08 — دليل ربط نماذج الذكاء الاصطناعي

> نسخة نصية من قسم **🔌 الربط** داخل البرنامج، للرجوع إليها في أي وقت.
> داخل البرنامج يوجد زر **🧪 اختبار الاتصال** لكل مزوّد: يرسل رسالة قصيرة ثابتة فقط (بلا أي معلومات شخصية)، ويعرض النتيجة وزمن الاستجابة، أو سبب الفشل والحل المقترح بالعربية.

## كيف يختار المساعد المزوّد؟
- يجرّب المزوّدين بالترتيب حسب «الوضع» في الإعدادات:
  - **هجين:** السحابي الأول، ثم الثاني، ثم Ollama.
  - **سحابي:** Claude و Gemini فقط.
  - **محلي:** Ollama فقط.
- إن تعذّر الجميع يجيب من **المعرفة المحلية** (بيانات المشاريع المسجّلة) دون أي اتصال.
- مفاتيح Claude و Gemini محفوظة **مشفرة داخل الخزنة**، ولا تُستخدم إلا والخزنة مفتوحة بكلمة المرور الرئيسية.
- بديل للمطوّرين: متغيرات البيئة `ANTHROPIC_API_KEY` و `GEMINI_API_KEY`.

## 🟠 Claude (Anthropic)
1. افتح `console.anthropic.com` وسجّل الدخول.
2. من **Settings ← Billing** أضف رصيداً؛ الاستخدام يُحاسب حسب حجم النص.
3. من **Settings ← API Keys** اضغط **Create Key** وانسخ المفتاح (يبدأ بـ `sk-ant-`).
4. في البرنامج: **الخزنة ← مفاتيح الذكاء الاصطناعي**، اختر Claude والصق المفتاح ثم احفظه.
5. اختر النموذج في الإعدادات:
   - `claude-opus-5-5`: الافتراضي والأقوى.
   - `claude-sonnet-5-5`: متوازن.
   - `claude-haiku-5-5`: الأسرع والأرخص.
6. اضغط **اختبار الاتصال**.

## 🔵 Gemini (Google)
1. افتح `aistudio.google.com` بحساب Google.
2. اضغط **Get API key** ثم **Create API key** وانسخ المفتاح (يبدأ بـ `AIza`).
3. الطبقة المجانية لها حدود يومية؛ للاستخدام الكثيف فعّل الفوترة في مشروع Google Cloud المرتبط بالمفتاح.
4. في البرنامج: **الخزنة ← مفاتيح الذكاء الاصطناعي**، اختر Gemini والصق المفتاح ثم احفظه.
5. النموذج الافتراضي `gemini-3.8-flash` (سريع ورخيص)، ويمكن تغييره من الإعدادات.
6. اضغط **اختبار الاتصال**.

## 🦙 Ollama (محلي، مجاني، يعمل بلا إنترنت)
### Windows
1. نزّل Ollama من `ollama.com/download` وثبّته؛ سيعمل في الخلفية تلقائياً.
2. نزّل نموذجاً من PowerShell:
   ```powershell
   ollama pull llama3.2
   ```
3. تأكد من وجوده:
   ```powershell
   ollama list
   ```
4. في الإعدادات اجعل العنوان `http://127.0.0.1:11434`، واكتب اسم النموذج كما ظهر في القائمة.

### macOS (MacBook Air)
1. نزّل Ollama للماك من `ollama.com/download`، واسحبه إلى Applications، ثم افتحه.
2. نزّل نموذجاً من Terminal:
   ```bash
   ollama pull llama3.2
   ```
3. استخدم نفس العنوان والإعدادات كما في Windows.

### أي نموذج يناسب الجهاز؟
| الجهاز | الاقتراح |
| :--- | :--- |
| مكتبي RTX 3090 (24GB) | نماذج حتى نحو 32 مليار معامل بضغط 4-bit (عائلات Qwen أو Gemma أو DeepSeek بأحجام 27B–32B) تعمل بالكامل على البطاقة. أقوى خيار محلي. |
| MacBook Air M5 | 3B–14B حسب الذاكرة الموحّدة: مع 16GB يناسبه نحو 8B، ومع 24–32GB حتى نحو 14B. |
| لابتوب Windows | حسب ذاكرة بطاقة الرسوميات؛ ابدأ بـ `llama3.2` (3B) وجرّب الأكبر تدريجياً. |

الأسماء والأحجام المتاحة في `ollama.com/library`.

> **ملاحظة:** حالياً يقبل البرنامج Ollama على **نفس الجهاز فقط** لأسباب أمنية.
> ربط Ollama المكتبي من اللابتوب والماك عبر النطاق على Cloudflare (مع Cloudflare Access) يُنفَّذ في المرحلة **د** من [خطة التوسعة](07-EXPANSION-PLAN.md).

### حل المشكلات الشائعة
| رسالة الاختبار | الحل |
| :--- | :--- |
| Ollama لا يعمل على هذا الجهاز | افتح برنامج Ollama، أو شغّل `ollama serve`. |
| النموذج غير مثبّت | شغّل `ollama pull <اسم النموذج>`، أو صحّح الاسم في الإعدادات. |
| غير مهيّأ: الخزنة مقفلة | افتح الخزنة بكلمة المرور الرئيسية؛ المفاتيح محفوظة داخلها. |
| مفتاح API غير صحيح | أنشئ مفتاحاً جديداً واحفظه من: الخزنة ← مفاتيح الذكاء الاصطناعي. |
| تجاوز حد الاستخدام | تحقق من الرصيد أو حدود الاستخدام في حساب المزوّد. |

## 🧩 الذاكرة المشتركة مع Claude Code و Antigravity (MCP)
- خادم الذاكرة `src/tools/mcp-memory-server.ts` يعمل عبر stdio، وفيه 6 أدوات `second_brain_*`. عبره يقرأ الوكيلان ملف القائد وسياق المشروع، ويسجّلان القرارات.
- التسجيل يدوياً على جهاز جديد (قبل المثبّت في المرحلة **ب**):
  1. خذ نسخة احتياطية من الملف `~/.claude.json` لـ Claude Code، ومن الملف `~/.gemini/antigravity/mcp_config.json` لـ Antigravity.
  2. أضف خادماً باسم `second-brain` بالأمر `node`، ومعامله المسار الكامل لملف `mcp-memory-server.ts`. استخدم الشرطة الأمامية `/` في المسار.
  3. أعد تشغيل الأداة، ثم تحقق من ظهور أدوات `second_brain_*`.
