# 08 — دليل ربط نماذج الذكاء الاصطناعي

> نسخة نصية من قسم **🔌 الربط** داخل البرنامج، للرجوع إليها في أي وقت.
> داخل البرنامج يوجد زر **🧪 اختبار الاتصال** لكل مزوّد: يرسل رسالة قصيرة ثابتة فقط (بلا أي معلومات شخصية)، ويعرض النتيجة وزمن الاستجابة، أو سبب الفشل والحل المقترح بالعربية.

## كيف يختار المساعد المزوّد؟ (بلا فواتير إضافية)
- يجرّب المزوّدين بالترتيب حسب «الوضع» في الإعدادات:
  - **هجين (الافتراضي):** Claude عبر اشتراكك، ثم Ollama.
  - **اشتراك Claude فقط:** Claude عبر اشتراكك وحده.
  - **محلي:** Ollama فقط.
- إن تعذّر الجميع يجيب من **المعرفة المحلية** (بيانات المشاريع المسجّلة) دون أي اتصال.
- **مفاتيح API** خيار متقدم مطفأ افتراضياً، لأنها تُحاسَب برصيد منفصل عن الاشتراكات (التفاصيل في آخر الدليل).

## 🟠 Claude عبر اشتراكك (Claude Pro)
يستخدم المساعد برنامج **Claude Code** على جهازك دون واجهة، فيعمل باشتراك Pro نفسه **بلا فاتورة إضافية**، ويُحسب الاستخدام من حصة الاشتراك.

### خطوات لمرة واحدة على كل جهاز (تقوم بها أنت)
1. **ثبّت الأمر `claude`** إن لم يكن متاحاً في الطرفية:
   - Windows (من PowerShell؛ يستخدم النسخة الموجودة داخل تطبيق Claude لسطح المكتب):
     ```powershell
     & (Get-ChildItem "$env:APPDATA\Claude\claude-code" -Recurse -Filter claude.exe | Sort-Object LastWriteTime -Descending | Select-Object -First 1).FullName install
     ```
   - macOS (من Terminal):
     ```bash
     curl -fsSL https://claude.ai/install.sh | bash
     ```
2. **افتح نافذة طرفية جديدة** وسجّل الدخول بحساب Claude Pro:
   ```powershell
   claude auth login
   ```
3. في البرنامج: قسم **🔌 الربط** ← بطاقة «Claude عبر اشتراكك» ← **اختبار الاتصال**.

### كيف يعمل بأمان؟
- كل الأدوات مطفأة، ولا خوادم MCP، ولا مهارات أو أوامر، ولا إعدادات مستخدم أو مشروع، ولا حفظ للجلسات.
- يعمل في مجلد مؤقت فارغ يُحذف بعد كل رد، فلا يستطيع قراءة ملفاتك أو تعديلها أو تنفيذ أوامر.
- إن ظهرت أي أداة أو خادم MCP عند بدء التشغيل، يوقفه البرنامج فوراً.
- تُزال `ANTHROPIC_API_KEY` وما يشبهها من البيئة قبل التشغيل، حتى لا يتحول الاستخدام إلى فوترة API دون علمك.
- البرنامج يبحث عن Claude Code تلقائياً: المسار المخصص في الإعدادات، ثم `PATH`، ثم `~/.local/bin`، ثم النسخة المضمّنة في تطبيق سطح المكتب.

### النموذج
- من الإعدادات: «نموذج Claude عبر الاشتراك». الافتراضي `sonnet` لتوفير الحصة، ويمكن اختيار `opus` للأقوى.

## 🔵 Gemini عبر Antigravity
- أوقفت Google استخدام Gemini CLI لحسابات الأفراد ووجّهتها إلى Antigravity، و Antigravity لا يعمل من برنامج آخر دون واجهته.
- لذلك يبقى Gemini مربوطاً عبر **الذاكرة المشتركة (MCP)** فقط: يقرأ ملفك وسياق مشاريعك ويسجّل القرارات أثناء عملك في Antigravity، باشتراكك وبلا تكلفة إضافية.

## 🦙 Ollama (محلي، مجاني، يعمل بلا إنترنت)
### Windows
1. نزّل Ollama من `ollama.com/download` وثبّته؛ سيعمل في الخلفية تلقائياً.
2. نزّل نموذجاً من PowerShell:
   ```powershell
   ollama pull llama3.2
   ```
3. تأكد من وجوده:
   ```powershell
   ollama list
   ```
4. في الإعدادات اجعل العنوان `http://127.0.0.1:11434`، واكتب اسم النموذج كما ظهر في القائمة.

### macOS (MacBook Air)
1. نزّل Ollama للماك من `ollama.com/download`، واسحبه إلى Applications، ثم افتحه.
2. نزّل نموذجاً من Terminal:
   ```bash
   ollama pull llama3.2
   ```
3. استخدم نفس العنوان والإعدادات كما في Windows.

### أي نموذج يناسب الجهاز؟
| الجهاز | الاقتراح |
| :--- | :--- |
| مكتبي RTX 3090 (24GB) | نماذج حتى نحو 32 مليار معامل بضغط 4-bit (عائلات Qwen أو Gemma أو DeepSeek بأحجام 27B–32B) تعمل بالكامل على البطاقة. أقوى خيار محلي. |
| MacBook Air M5 | 3B–14B حسب الذاكرة الموحّدة: مع 16GB يناسبه نحو 8B، ومع 24–32GB حتى نحو 14B. |
| لابتوب Windows | حسب ذاكرة بطاقة الرسوميات؛ ابدأ بـ `llama3.2` (3B) وجرّب الأكبر تدريجياً. |

الأسماء والأحجام المتاحة في `ollama.com/library`.

> **قادماً — `ollama launch claude`:** يشغّل Ollama برنامج Claude Code نفسه على نماذج Ollama (المكتبي أو المحلي)، مجاناً وبلا استهلاك لحصة Pro. سيُضاف كخيار تراجع وكدليل للعمل اليومي بعد المرحلة **د** (البند أ٢.4 في [خطة التوسعة](07-EXPANSION-PLAN.md)).

> **ملاحظة:** حالياً يقبل البرنامج Ollama على **نفس الجهاز فقط** لأسباب أمنية.
> ربط Ollama المكتبي من اللابتوب والماك عبر النطاق على Cloudflare (مع Cloudflare Access) يُنفَّذ في المرحلة **د** من [خطة التوسعة](07-EXPANSION-PLAN.md).

### حل المشكلات الشائعة
| رسالة الاختبار | الحل |
| :--- | :--- |
| Claude Code غير مثبّت على هذا الجهاز | نفّذ خطوة التثبيت أعلاه، أو حدّد مساره في الإعدادات. |
| Claude Code غير مسجّل الدخول باشتراكك | شغّل `claude auth login` وسجّل الدخول بحساب Pro. |
| تم بلوغ حد استخدام اشتراك Claude | انتظر تجدد الحصة؛ يجيب Ollama أو المعرفة المحلية حتى ذلك الحين. |
| Ollama لا يعمل على هذا الجهاز | افتح برنامج Ollama، أو شغّل `ollama serve`. |
| النموذج غير مثبّت | شغّل `ollama pull <اسم النموذج>`، أو صحّح الاسم في الإعدادات. |
| غير مهيّأ: الخزنة مقفلة | افتح الخزنة بكلمة المرور الرئيسية؛ المفاتيح محفوظة داخلها. |
| مفتاح API غير صحيح | أنشئ مفتاحاً جديداً واحفظه من: الخزنة ← مفاتيح الذكاء الاصطناعي. |
| تجاوز حد الاستخدام | تحقق من الرصيد أو حدود الاستخدام في حساب المزوّد. |

## 🔊 الصوت العربي
- يُولَّد الصوت **على جهازك نفسه** بلا إنترنت ولا خدمة خارجية، ويعمل في أي متصفح.
- **XTTS-v2 (الأعلى جودة، المعتمد):** صوتا **Suad Qasim** (الافتراضي) و **Damien Black**، ويُختار الصوت لكل جهاز من بطاقة «🔊 الصوت العربي».
  - يُحمَّل في الخلفية عند تشغيل البرنامج (نحو نصف دقيقة)، ثم تُولَّد كل جملة في 2–3 ثوانٍ على كرت الشاشة. أثناء التحميل يُستخدم Kareem حتى لا يتأخر الرد.
  - يُطفأ بعد 30 دقيقة بلا استخدام لتحرير ذاكرة كرت الشاشة (نحو 2GB)، ويعود تلقائياً عند أول طلب.
  - **الرخصة:** Coqui Public Model License — للاستخدام الشخصي غير التجاري فقط.
  - التثبيت على جهاز آخر (Python 3.12، نحو 4.8GB تنزيلاً و 7GB على القرص):
    ```powershell
    node src/tools/install-xtts-voice.ts --accept-license
    ```
  - مصدر النموذج: `huggingface.co/tts-hub/XTTS-v2` (المصدر الذي تعتمده مكتبة `coqui-tts` 0.28)، ويُحفظ في مجلد Hugging Face في ملف المستخدم. يُحمَّل بوضع الأوزان فقط، فلا يمكن أن ينفّذ كوداً.
- **الصوت العربي المدمج Kareem (احتياطي خفيف):** من قسم **🔌 الربط ← الصوت العربي** اضغط **تنزيل الصوت العربي المدمج**. يُنزَّل نحو 85MB مرة واحدة على كل جهاز، من المصادر الرسمية فقط: محرك Piper من GitHub، والصوت «Kareem» من Hugging Face. أو من الطرفية:
  ```powershell
  node src/tools/install-arabic-voice.ts
  ```
- **أو صوت Windows العربي:** إعدادات Windows ← الوقت واللغة ← الكلام ← إضافة أصوات ← العربية (السعودية). يستخدمه البرنامج حتى لو لم يظهر في Chrome.
- زر **«الرد الصوتي: يعمل/متوقف»** في المحادثة يبدّل النطق التلقائي لهذا الجهاز.

## ⚙️ متقدم: مفاتيح API (فوترة منفصلة)
> لا يستخدمها المساعد إلا بعد تفعيل **«استخدام مفاتيح API»** في الإعدادات ← الذكاء الاصطناعي ← متقدم. عندها تأتي بعد الاشتراك وقبل Ollama.
> المفاتيح محفوظة **مشفرة داخل الخزنة**، ولا تُستخدم إلا والخزنة مفتوحة. بديل للمطوّرين: متغيرات البيئة `ANTHROPIC_API_KEY` و `GEMINI_API_KEY`.

### 🟠 Claude API (Anthropic)
1. افتح `console.anthropic.com` وسجّل الدخول.
2. من **Settings ← Billing** أضف رصيداً؛ الاستخدام يُحاسب حسب حجم النص.
3. من **Settings ← API Keys** اضغط **Create Key** وانسخ المفتاح (يبدأ بـ `sk-ant-`).
4. في البرنامج: **الخزنة ← مفاتيح الذكاء الاصطناعي**، اختر Claude والصق المفتاح ثم احفظه.
5. اختر النموذج في الإعدادات:
   - `claude-opus-5-5`: الافتراضي والأقوى.
   - `claude-sonnet-5-5`: متوازن.
   - `claude-haiku-5-5`: الأسرع والأرخص.
6. اضغط **اختبار الاتصال**.

### 🔵 Gemini API (Google)
1. افتح `aistudio.google.com` بحساب Google.
2. اضغط **Get API key** ثم **Create API key** وانسخ المفتاح (يبدأ بـ `AIza`).
3. الطبقة المجانية لها حدود يومية؛ للاستخدام الكثيف فعّل الفوترة في مشروع Google Cloud المرتبط بالمفتاح.
4. في البرنامج: **الخزنة ← مفاتيح الذكاء الاصطناعي**، اختر Gemini والصق المفتاح ثم احفظه.
5. النموذج الافتراضي `gemini-3.8-flash` (سريع ورخيص)، ويمكن تغييره من الإعدادات.
6. اضغط **اختبار الاتصال**.

## 🧩 الذاكرة المشتركة مع Claude Code و Antigravity (MCP)
- خادم الذاكرة `src/tools/mcp-memory-server.ts` يعمل عبر stdio، وفيه 6 أدوات `second_brain_*`. عبره يقرأ الوكيلان ملف القائد وسياق المشروع، ويسجّلان القرارات.
- التسجيل يدوياً على جهاز جديد (قبل المثبّت في المرحلة **ب**):
  1. خذ نسخة احتياطية من الملف `~/.claude.json` لـ Claude Code، ومن الملف `~/.gemini/antigravity/mcp_config.json` لـ Antigravity.
  2. أضف خادماً باسم `second-brain` بالأمر `node`، ومعامله المسار الكامل لملف `mcp-memory-server.ts`. استخدم الشرطة الأمامية `/` في المسار.
  3. أعد تشغيل الأداة، ثم تحقق من ظهور أدوات `second_brain_*`.
