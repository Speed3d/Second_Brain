> **يا Claude على الماك:** اقرأ هذا الملف كاملاً أولاً، ثم [`CONSTITUTION-AND-RULES.md`](../CONSTITUTION-AND-RULES.md)، ثم [`docs/07-EXPANSION-PLAN.md`](07-EXPANSION-PLAN.md)، ثم [`CHANGELOG.md`](../CHANGELOG.md). نفّذ الخطوات بالترتيب، وحدّث حالة كل بند في القسم الأخير.
> **كُتب في:** 2026-11-13، عند الإصدار **1.8.1**.

## 2. نقل المشروع إلى الماك

### ما يُنقل
انقل مجلد `Second Brain` كاملاً (فيه الخزنة المشفرة والإعدادات والمحادثات وتاريخ Git). **باستثناء:**

| لا تنقل | السبب |
| :--- | :--- |
| `Second-Brain-System/vendor/` (5.4GB) | برامج Windows: Piper لـ Windows وبيئة Python لـ Windows. تُثبَّت نسخ الماك من جديد بالخطوة 5. |
| `Second-Brain-System/data/device.json` | هوية جهاز Windows؛ الماك يجب أن يأخذ هويته الخاصة من المثبّت. |
| `Second-Brain-System/data/logs/` | سجلات Windows (اختياري). |

### طريقة النقل
- **فلاشة USB، أو AirDrop، أو قرص خارجي.** لا ترفع نسخة غير مشفرة إلى أي خدمة سحابية.
- الخزنة نفسها مشفرة، لكن مجلد `data/` فيه المحادثات المشفرة والذاكرة والإعدادات.
- **مكان مقترح على الماك:** `~/Second Brain` (المسار الذي فيه مسافة مدعوم).

### بعد النقل: إزالة علامة الحجر
الملفات المنقولة بـ AirDrop أو من الإنترنت تحمل علامة «حجر» تمنع تشغيل السكربتات. أزلها مرة واحدة:
```bash
xattr -dr com.apple.quarantine ~/"Second Brain"
```

## 4. الخطوات بالترتيب (مع النتيجة المتوقعة)

كل الأوامر من داخل `~/Second Brain/Second-Brain-System`.

### الخطوة 1 — الاختبارات أولاً
```bash
node tests/run-all-tests.ts
```
- **المتوقع:** نجاح كل الحزم. اختبارات PowerShell ووضع المعاينة في حزمة 14 تُتخطى تلقائياً على الماك، فقد يقل عدد الفحوص عن 70.
- **إن فشل شيء:** أصلحه أولاً، فقد يكون فرقاً بين Windows و macOS، مثل مسار أو أمر.

### الخطوة 2 — معاينة المثبّت
```bash
bash install/macos/install-macos.sh --preview
```
- **المتوقع:** يعرض المسارات و Node.js، ثم «وضع المعاينة: لم يُغيَّر أي شيء».

### الخطوة 3 — التثبيت (بعد موافقة القائد)
```bash
bash install/macos/install-macos.sh --device-name "MacBook-M5"
```
- **المتوقع:**
  - ✔ LaunchAgent: `~/Library/LaunchAgents/com.secondbrain.server.plist`.
  - ✔ ملف «Second Brain.command» على سطح المكتب.
  - ✔ اسم الجهاز.
- **تحقّق:**
  ```bash
  curl -s http://127.0.0.1:4777/api/health
  ```
  يجب أن يرد بـ `"version":"1.8.1"`.

### الخطوة 4 — النافذة المستقلة
- افتح «Second Brain.command» من سطح المكتب. يجب أن تُفتح نافذة Chrome مستقلة بلا شريط عنوان، والشعار في الشريط العلوي.
- **تحقّق في الواجهة:**
  - افتح الخزنة بكلمة المرور الرئيسية.
  - المحادثات المحفوظة تظهر في «🗂 المحادثات المحفوظة».
  - المشاريع الثلاثة تظهر بمسارات Windows، وهذا متوقع ويُحل في المرحلة ج. **لا تحذفها.**

### الخطوة 5 — الصوت العربي على الماك
1. الصوت الخفيف Kareem (Piper لـ Apple Silicon، نحو 80MB):
   ```bash
   node src/tools/install-arabic-voice.ts
   ```
2. ثم في الواجهة: «🔌 الربط ← 🔊 الصوت العربي ← تجربة الصوت».
3. **XTTS-v2 (اختياري، نحو 4.8GB):** يعمل على الماك بالمعالج، وقد يكون بطيئاً. قِس زمن الجملة قبل اعتماده:
   ```bash
   node src/tools/install-xtts-voice.ts --accept-license
   ```
   القائد وافق على رخصة Coqui (استخدام شخصي غير تجاري) على Windows. **أكّد معه قبل التنزيل على الماك.**

### الخطوة 6 — Claude عبر الاشتراك
بعد `claude auth login`، اذهب إلى «🔌 الربط ← Claude عبر اشتراكك ← اختبار الاتصال». **المتوقع:** «✅ يعمل».

### الخطوة 7 — قائمة تحقق المرحلة ب على الماك
- [ ] بعد تسجيل الخروج ثم الدخول، يعمل الخادم تلقائياً (`curl .../api/health`).
- [ ] إيقاف الخادم بالقوة يعيده خلال نحو 10 ثوانٍ (`KeepAlive`):
  ```bash
  pkill -f desktop-server.ts
  ```
- [ ] النافذة المستقلة تُفتح من سطح المكتب، والشعار ظاهر.
- [ ] الصوت العربي يُسمع في Chrome.
- [ ] الإزالة توقف الخدمة وتحذف الملفات، والبيانات سليمة:
  ```bash
  bash install/macos/uninstall-macos.sh
  ```
  ثم أعد التثبيت.
- [ ] الاختبارات تنجح على الماك.

## 5. نقاط يجب الانتباه لها (لم تُجرَّب بعد على ماك فعلي)

1. **حزمة Piper للماك** (`piper_macos_aarch64.tar.gz`): افترضنا أنها تُفك إلى `vendor/piper/piper`. إن اختلف الهيكل، عدّل `resolvePiperPaths()` في `src/features/voice/tts-service.ts`.
2. **LaunchAgent:** يعمل ببيئة محدودة (PATH قصير).
   - مسار `node` مكتوب صراحة في ملف plist.
   - Claude Code يُبحث عنه في `~/.local/bin` تلقائياً.
   - إن لم يظهر، راجع `locateClaudeCli()` في `claude-cli-provider.ts`.
3. **أصوات macOS:** إن لم يُنزَّل Piper يُستخدم `say` بصوت عربي (مثل Majed) إن كان مثبّتاً من «إعدادات النظام ← إمكانية الوصول ← المحتوى المنطوق».
4. **مسارات المشاريع:** تبقى بمسارات Windows حتى المرحلة ج، التي تحفظ مساراً خاصاً لكل جهاز.
5. **الخزنة:** نفس الملف ونفس كلمة المرور. التشفير مستقل عن نظام التشغيل.

## 6. قواعد ملزمة لجلسة الماك (مختصر الدستور)

- **الاسم:** «Second Brain» أو «العقل الثاني». الردود بالعربية.
- **المستودع عام:**
  - يُرفع الكود والوثائق فقط، **وبموافقة القائد الصريحة**.
  - لا يُرفع `data/` ولا `vendor/` ولا `config/branding.json` ولا `config/settings.json` ولا المحتوى الشخصي في Obsidian.
  - قبل كل commit يُفحص التغيير بحثاً عن البريد والأسرار واسم المستخدم.
- **القانون التاسع:** كل تعديل يرفع الإصدار في `Second-Brain-System/package.json`، ويُضاف قسم في `CHANGELOG.md`. تعديلات الماك المتوقعة: **1.8.2** للإصلاحات، أو **1.9.0** إن أُضيفت ميزة.
- **التوثيق:** حدّث `docs/03` و `docs/07` وهذا الملف مع كل خطوة.
- **تسجيل الدخول** (Claude، أي حساب) يقوم به القائد بنفسه. أي تعديل على إعدادات برامج أخرى يُعرض أولاً مع نسخة احتياطية.
- **الاختبارات** لا تلمس البيانات الحقيقية أبداً، وتعمل في بيئة معزولة.

## 7. بعد الماك: العودة إلى Windows
1. ارفع تغييرات الماك إلى GitHub بموافقة القائد، ثم اسحبها على Windows (`git pull`).
2. **المرحلة ج — المزامنة:**
   - Google Drive، وقفل الكتابة.
   - مسارات المشاريع لكل جهاز، وهوية الجهاز موجودة الآن في `data/device.json`.
3. **المرحلة د — Ollama الموزّع:**
   - المكتبي RTX 3090 عبر Cloudflare.
   - البند أ٢.4 `ollama launch claude`.
   - XTTS على المكتبي.
4. **المرحلة هـ — «أجهزتي»:** RustDesk و Wake-on-LAN.
